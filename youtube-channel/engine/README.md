# Brevane অ্যানিমেশন ইঞ্জিন (ডেমো সংস্করণ)

পুরো ভিডিও কোডে আঁকা হয়, কোনো AI ছবি বা ভিডিও জেনারেটর লাগে না।

- `scene.js`: চরিত্র (Nev), ঘর, ফোন, ক্যামেরা, সাবটাইটেল আর দৃশ্যের সময়রেখা। `draw(ctx, t)` সময় t-এর ফ্রেম আঁকে।
- `render.js`: Chromium-এ প্রতিটা ফ্রেম এঁকে ffmpeg-এ পাঠায়, তারপর MP4 বানায়।

চালানোর নিয়ম:
```
node render.js video.mp4 30          # পুরো ভিডিও, 30fps
node render.js x.mp4 30 2,11,19      # শুধু ওই সময়গুলোর স্থির ছবি (still_*.jpg)
```
শব্দ এখন ffmpeg দিয়ে আলাদা বানিয়ে জোড়া হয়। কণ্ঠ (Gemini TTS) পরে যোগ হবে।

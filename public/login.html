📲 কীভাবে ইনস্টল করব?

Android (Chrome): ওপরে ডানে ⋮ চাপো → Install app বা Add to Home screen → Install।

iPhone (Safari): নিচের শেয়ার ⬆️ চাপো → Add to Home Screen → Add।

অ্যাপটা অবশ্যই Chrome (iPhone-এ Safari) ব্রাউজারে খুলতে হবে। Facebook, Messenger বা অন্য অ্যাপের ভেতরের ব্রাউজারে ইনস্টল হয় না।

শুধু অনুমতি পাওয়া Gmail দিয়ে ঢোকা যাবে। প্রত্যেকের নিজের আলাদা প্রোফাইল থাকে।
